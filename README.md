# 🏃‍♂️ 걸포 Run - 김포걸포초 건강체력 달리기 트래커

김포걸포초등학교 학생들의 자율 달리기 습관 형성과 심폐지구력 증진을 위한 2단계 초간편 모바일 최적화 웹 애플리케이션입니다.

---

## 🌟 화면 흐름 및 주요 특징

### 📱 초간단 2단계 화면 구성
1. **Main 화면**:
   - **A 영역**: 걸포초등학교 공식 마크 엠블럼 + **걸포 Run** 브랜드 헤더
   - **B 영역**: **🏆 반별등수** 실시간 학급 누적 순위 보드 (1위, 2위, 3위 메달 및 누적 바퀴/거리)
   - **입력란**: 손그림 스케치를 그대로 반영한 직관적인 `[ ] 학년   [ ] 반   [  ] 번`
   - **버튼**: `[ 입력하기 ]` 클릭 시 Second 화면으로 즉시 전환
2. **Second 화면**:
   - 상단: `3학년 1반 15번 학생` 대상 안내 및 `← 메인 화면` 뒤로가기
   - 중앙: 시원하고 큼직한 `[      ] 바퀴` 입력 필드 (+ / − 버튼 및 1·2·3·5·10바퀴 원터치 칩)
   - 하단: `[ 확  인 ]` 버튼 클릭 시 즉시 저장 완료 팝업 후 메인 화면 복귀 & 반별등수 자동 갱신! (-끝-)
4. **선생님 전용 관리자 모드**:
   - 관리자 CODE (기본값: `1378`)로 보안 접속
   - 날짜별/학년별/학급별 실시간 필터 및 학생 오입력 수정/삭제
   - **엑셀(CSV) 즉시 다운로드**: 한글 깨짐 없는 엑셀 호환 UTF-8 BOM 지원 (NEIS/체육 평가 자료 활용)
   - 운동장 1바퀴 기본 길이(150m, 200m 등) 자유 변경
5. **데이터 영구 보존**:
   - 기본적으로 브라우저 로컬 저장소에 영구 보존
   - 내장된 `geolporun` Firebase 프로젝트로 자동 연결 및 실시간 공유

VS Code의 `Live Server` 확장을 사용하시거나, 터미널에서 다음 명령어를 실행하면 스마트폰으로도 같은 와이파이에서 접속할 수 있습니다.
```bash

python -m http.server 8080
```

교사 컴퓨터를 켜둘 필요 없이 학생들이 언제 어디서나 접속할 수 있도록 **1분 만에 무료 배포**하는 방법입니다.

2. 현재 프로젝트 폴더를 드래그 앤 드롭하거나 GitHub에 업로드 후 Vercel과 연결

4. 해당 주소를 [QR코드 생성 사이트](https://www.qrcode-monkey.com)에서 QR코드로 만들어 운동장이나 교실에 부착하시면 끝납니다.

### [추천 2] GitHub Pages 무료 배포
1. GitHub 리포지토리에 현재 파일들을 업로드
2. 리포지토리의 `Settings` -> `Pages` -> Source를 `main` 브랜치로 지정
3. 무료 주소(`https://계정명.github.io/리포지토리명`)로 즉시 운영 가능

## 🔥 파이어베이스(Firebase) 실시간 클라우드 DB 연동 가이드

여러 학생이 각자의 스마트폰이나 태블릿에서 입력한 기록을 **하나의 전교생 실시간 데이터베이스에 모으고 실시간 반별 등수를 공유**하려면 구글 파이어베이스(무료)를 연동하시면 됩니다.

### 1단계. Firebase 프로젝트 만들기 (1분 소요)
1. [Firebase 콘솔](https://console.firebase.google.com)에 구글 계정으로 로그인합니다.
2. **[프로젝트 만들기]** 버튼 클릭
3. 프로젝트 이름 입력 (예: `geolpo-run`) 후 계속 진행 (Google 애널리틱스는 해제해도 무방합니다) ➡️ 프로젝트 생성 완료

### 2단계. Firestore 데이터베이스 활성화
1. 좌측 메뉴에서 **빌드(Build)** ➡️ **Firestore Database**를 클릭합니다.
2. **[데이터베이스 만들기]** 클릭
3. 데이터베이스 위치를 `asia-northeast3 (Seoul)`로 선택합니다.
4. 보안 규칙 단계에서 **[테스트 모드에서 시작]** 선택 후 생성 완료합니다.

### 3단계. 보안 규칙(Rules) 설정 (필수)

이 프로젝트는 별도의 교사 Google 로그인 없이 운영하는 간편 모드를 사용합니다. 프로젝트의 `firestore.rules.example`에는 다음 정책을 적용한 규칙이 들어 있습니다.

- 학생: 순위 조회와 형식에 맞는 새 기록 추가 가능
- 웹 관리자 화면: 4자리 CODE 확인 후 기록 수정·삭제 가능
- 임의 필드, 비정상 학년·반·번호·바퀴 수 저장 차단

Firebase 콘솔의 **Firestore Database → 규칙**에서 이 파일의 내용을 적용할 수 있습니다. 이 방식에서는 Firebase Auth를 설정할 필요가 없습니다.

> 주의: 4자리 관리자 CODE는 웹 화면 접근을 막는 용도이며 Firestore 서버 권한은 아닙니다. 데이터베이스 주소와 사용법을 아는 사용자는 앱을 거치지 않고 기록을 변경하거나 삭제할 수 있습니다. 담당자가 Firebase 콘솔을 주기적으로 확인하고 CSV 백업을 보관하는 소규모 학교 운영을 전제로 합니다.

### 4단계. 자동 연결 확인

Firebase 웹 앱 설정은 `js/db.js`에 내장되어 있으므로 관리자 화면에서 별도로 입력할 필요가 없습니다. 웹페이지를 열면 `geolporun` 프로젝트에 자동으로 연결되고 모든 학생의 기록이 실시간으로 동기화됩니다.

### 동기화 동작

- 기록은 먼저 해당 기기의 LocalStorage에 저장됩니다.
- Firestore 업로드에 실패하면 `pending` 상태로 보관하며 인터넷 연결 복구 시 자동 재전송합니다.
- 반별 순위는 Firestore 실시간 구독을 사용하여 다른 기기의 입력도 자동 반영합니다.
- Firebase 연결 설정은 실수로 변경되지 않도록 관리자 화면에서 숨기고 내장값으로 고정했습니다.
